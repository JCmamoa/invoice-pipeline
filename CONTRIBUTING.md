# Contributing

## Language policy

**All repository artifacts are written in English**: code, identifiers,
comments, SQL, documentation, scripts, log messages, metric names, commit
messages and pull request descriptions. Chat with the maintainer may be in
Portuguese, but anything committed is English.

## Setup

```bash
docker compose up -d --build     # full stack
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"          # tests and lint on the host
```

The stack is enough to exercise the product. The host environment is only needed
for the unit tests, lint and the integration test.

## Before opening a pull request

```bash
ruff check .
pytest
docker compose config >/dev/null
```

Integration test (requires Postgres with `db/001_schema.sql` applied):

```bash
TEST_DATABASE_URL='postgresql://invoice:invoice@localhost:5434/invoice' \
  pytest tests/test_api_integration.py -v
```

If you change extraction or validation behavior, add a test. The sample PDFs are
generated by `scripts/make_samples.py`; regenerate them if you change their
content.

## Code conventions

- Keep the LLM output untrusted: parse it with Pydantic and validate it
  deterministically.
- Never fabricate a field. Missing data is `NULL` plus a validation reason.
- Wrap external calls (LLM, webhook) with timeouts and classify errors as
  transient or permanent.
- A single invoice must never crash the worker loop.
- Use `extra={...}` in log calls for `invoice_id`, `status`, `attempt` and
  `error`; the JSON formatter picks them up.
- Add new settings to `config.Settings.from_env`, `.env.example` and
  `docs/OPERATIONS.md`.
- Metric names follow `invoice_<thing>_total`.

## Commit style

Short, imperative subjects in English:

```
api: reject non-PDF uploads
worker: requeue stale processing claims
docs: document the IMAP trigger
```

Use a prefix for the affected area (`api`, `worker`, `extractor`, `db`, `docs`,
`ci`).

## CI

`.github/workflows/ci.yml` runs on every push to `main` and on pull requests:

| Job | What it does |
|---|---|
| `unit tests` | `ruff check`, `pytest`, `docker compose config` |
| `api integration` | Postgres service, schema, end-to-end API test |
| `build image` | Docker build |

A pull request must be green before merging.
