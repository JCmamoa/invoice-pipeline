# Sample invoices

Text-based PDFs generated by `scripts/make_samples.py`, plus one image-only
"scan" that exercises the OCR fallback.

| File | Expected result |
|---|---|
| `acme_invoice.pdf` | `processed` (BRL) |
| `globex_invoice.pdf` | `processed` (USD, Portuguese labels) |
| `missing_due_date.pdf` | `needs_review` — `missing_due_date` |
| `invalid_cnpj.pdf` | `needs_review` — `invalid_cnpj` |
| `scanned_invoice.pdf` | `processed` via OCR when `OCR_ENABLED=true`; `needs_review` (`no_text_layer`) when OCR is off |

The scanned sample has no embedded text: the text is rendered into an image and
saved as a PDF, exactly like a scanner would produce. It is 60 KB because it
contains a bitmap, not a text layer.

Regenerate them with:

```bash
pip install pillow
python3 scripts/make_samples.py
```

`pillow` is only needed to regenerate `scanned_invoice.pdf`; the runtime image
reads the committed file.
